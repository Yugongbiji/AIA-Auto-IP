# AIA Auto IP 账号表达风格规则 V1

## 1. 字段定位

原 `contentTone` 不再解释为抽象的“账号气质”，统一定义为 **账号表达风格**。

它回答的问题不是“这个人是什么性格”，而是：

> **以后这个账号的内容，应该用什么方式说话？**

该字段必须直接参与脚本改写，而不是只用于 IP 方案展示。

## 2. 询问方式

推荐问题：

> 你希望自己的内容说起话来是什么感觉？可以选 1～2 个最像你的风格，也可以自己补充。

默认快捷选项：

- 专业理性
- 亲和温暖
- 风趣幽默
- 干练直接
- 生活化真诚
- 观点鲜明
- 沉稳可信
- 轻松有梗

允许多选，建议 1～2 个。用户也可以自由补充，例如“像朋友聊天”“有点毒舌但不冒犯”“知识型但别太学院派”。

不建议强制用户从很多人格形容词中选满若干项；选择越多，实际表达越容易互相抵消。

## 3. 八类默认风格的写作含义

### 专业理性

- 结构清楚、逻辑明确；
- 先解释再下结论；
- 少夸张、少情绪化；
- 复杂内容尽量讲明白，不堆术语。

### 亲和温暖

- 像靠谱、好相处的朋友聊天；
- 可以有共情，但不煽情；
- 少说教、少端着；
- 多生活化表达。

### 风趣幽默

- 可以用轻巧比喻、反差、适度幽默；
- 让知识更容易读，不追求段段搞笑；
- 不油腻、不硬玩梗；
- 不能为了幽默牺牲专业准确性和合规边界。

### 干练直接

- 重点前置；
- 短句优先；
- 少铺垫、少绕圈；
- 快速进入判断、方法和结论。

### 生活化真诚

- 像真实的人在讲观察和经验；
- 多具体场景、口语表达；
- 少营销腔和包装词；
- 不虚构个人经历来制造真实感。

### 观点鲜明

- 可以有明确判断和立场；
- 开头可以更有观点张力；
- 观点和事实必须区分；
- 不把个人判断包装成绝对结论。

### 沉稳可信

- 克制、稳定、不急着说服；
- 强调长期视角和边界；
- 少网络热词、少煽动；
- 适合需要建立专业信任的内容。

### 轻松有梗

- 整体节奏轻松；
- 可以自然使用少量网感表达和俏皮话；
- 不连续抖机灵；
- 梗服务于理解和阅读，不抢内容本身的戏。

## 4. 多风格组合规则

如果用户选择两项，不是机械各写一半，而是组合为一个统一表达：

- `专业理性 + 亲和温暖`：专业但不端着，讲清楚也好接近；
- `风趣幽默 + 专业理性`：用轻松方式讲专业内容，事实和逻辑仍优先；
- `观点鲜明 + 干练直接`：结论清楚、节奏快，但保留事实边界；
- `生活化真诚 + 轻松有梗`：像真实朋友分享，轻松但不演段子。

若用户选择的风格存在明显张力，例如“沉稳可信 + 轻松有梗”，以内容类型决定强弱：专业风险内容优先沉稳，生活话题可以更轻松。

## 5. 脚本改写联动

脚本改写请求必须带入已确认的 `contentTone`，并转换成明确的 `scriptStyleGuide`。

硬规则：

- 风格影响 **表达方式**，不改变原稿事实、数据、产品责任、核心观点；
- 风格不能突破合规规则；
- 纯知识、产品责任、政策等高准确性内容，风格只能轻度介入；
- 个人观点、生活案例、口播表达等内容，可以更明显地体现风格；
- 没有确认风格时，不允许 AI 擅自给用户套“幽默”“毒舌”“治愈”等人设。

## 6. 数据与展示

- 继续使用现有字段名 `contentTone`，避免为一次命名调整做数据库迁移；
- 面向用户统一显示为“账号表达风格”；
- `scriptStyleGuide` 是内部派生字段，不在资料卡中展示，也不需要用户填写；
- 用户后续通过聊天明确修改表达风格时，应更新 `contentTone`，下一次脚本改写自动使用新风格。
