# 账号装修合规规则（来自《账号装修合规文档.xlsx》）

> 规则提供方：公司合规 + 小红书平台。代码化版本见 `../src/compliance.js`。
> 最后整理：2026-08。
> **注意：本文件记录“合规允许边界”，不等于产品一定会主动推荐。当前产品生成若采用更严格规则，以 `CURRENT_EFFECTIVE_REQUIREMENTS_LEDGER` / 对应唯一 Owner 为准。**

## 一、简介（Bio）

| 场景 | 合规要求 | 要求方 |
|---|---|---|
| 联系方式 | 简介区不得留电话、微信号等任何外部联系方式 | 公司合规 |
| 引流/诱导 | 不得含微信号、手机号、邮箱、QQ、微博；不得引导关注、利益诱导 | 小红书平台 |
| 敏感行业词 | 小红书简介不得出现：保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学等 | 小红书平台 |
| 执业证 | 小红书个人介绍里不能写执业证编号 | 小红书平台 |
| 可用称谓 | 合规资料允许的称谓仍需经过当前产品生成策略二次过滤 | 小红书平台 / 产品规则 |
| 小红书声明 | 简介最后一句固定加：`本账号所述内容为个人意见，不代表任何官方意见。` | 公司合规 |
| 视频号/抖音声明 | 简介最后连续放置且顺序固定：①个人意见声明 ②营销服务部 ③执业证编号；不得拆开 | 公司合规 |
| 品牌字 | 简介正文不可写友邦/AIA；视频号/抖音强制声明中的“友邦人寿”除外 | 公司合规 |

### 简介末尾顺序铁律

- 小红书：正文 → **最后一句合规声明**。
- 视频号 / 抖音：正文 → **个人意见声明 → 营销服务部 → 执业证编号**。
- 固定合规块必须连续，不得拆散。
- **营销员编号 ≠ 执业证编号**。`agentId` 只用于身份/资料匹配，不得输出为执业证编号。
- 未采集真实执业证编号时，Preview 可使用 `000` 占位，并提醒发布前替换。
- 固定尾部只由 `web/ip-policy-core.js:complianceFooter()` 追加；Prompt、AI 原始输出、旧 Vxx 不得再生成第二份。

## 二、昵称 & 唯一识别号

### 原始合规边界

- 账号唯一识别号（微信号 / 小红书号 / 抖音号）不得包含友邦及附属变体：友邦、友邦保险、友邦人寿、AIA、YOUBANG 等。
- 原公司材料中，对“昵称”在明确说明与友邦关系等条件下存在一定可用空间。

### 当前产品生成规则（更严格）

AIA Auto IP **不会主动生成或推荐含“友邦 / AIA / 保险”品牌或行业标签的昵称**。这是产品策略比最低合规边界更严格的选择，目的是避免平台风险、机械职业标签和后续规则分叉。

因此：
- 不得因为“合规材料允许某条件下使用”就恢复 `友邦+A称呼` 或 `AIA+A称呼` 推荐模板；
- 最终昵称仍必须遵守 `web/nickname-policy-v1.js` 的人物称呼、证据和自然表达规则；
- 原有昵称如含相关词，只能进入谨慎审查，不自动作为推荐候选。

## 三、头像

- 不得直接使用友邦所有的商标、服务标记、图标作为头像主体；
- 可用符合公司规范的真实场景照片，具体仍以公司最新合规要求为准。

## 四、小红书主页打卡图片

- 不可使用“友邦 / 友邦保险 / 招募 / 招聘 / 寻找友邦合伙人”等明显招募字样；
- 不得以个人名义直接招募、招聘保险营销员；
- 其他边界以公司最新合规材料为准。

## 五、视频 / 图文笔记（非简介）

视频/图文正文与“个人简介”不是同一规则场景。正文是否可出现品牌、产品和专业内容，按公司现行内容合规规则判断；不得把“正文可以出现”错误推广成“简介也可以出现”。

## 六、违规判定红线

### 医疗引流

- 引导线上/线下问诊、提供医疗服务；
- 引导评论区讨论疾病；
- 引导到站外学习医疗知识/领取资料；
- “疾病名称 + 引导沟通”属于高风险组合。

### 招商加盟 / 个人招募

- 为品牌/业务招商加盟；
- 诱导项目创业/项目投资；
- 以个人名义进行不符合公司规范的招募/招聘。

## 七、修改次数提醒

| 项目 | 当前产品固定提醒口径 |
|---|---|
| 视频号昵称 | 每年最多可修改 **5 次** |
| 微信视频号简介 | 暂无明确修改次数限制 |
| 小红书个人简介 | **7 天内最多修改 3 次，频繁修改也可能影响账号稳定** |

平台规则可能变化，最终以平台实时提示和公司最新合规通知为准。
