# 账号装修合规规则（来自《账号装修合规文档.xlsx》）

> 规则提供方：公司合规 + 小红书平台。代码化版本见 `../src/compliance.js`。
> 最后整理：2026-08

## 一、简介（Bio）

| 场景 | 合规要求 | 要求方 |
|------|----------|--------|
| 联系方式 | 简介区不得留电话、微信号等任何外部联系方式 | 公司合规 |
| 引流/诱导 | 不得含微信号、手机号、邮箱、QQ、微博；不得引导关注、利益诱导（关注送福利、私信领好处） | 小红书平台 |
| 敏感行业词 | 不得出现：保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学等 | 小红书平台 |
| 执业证 | 个人介绍里不能写执业证编号 | 小红书平台 |
| 可用称谓 | 保险代理人可用「代理人」「养老规划师」 | 小红书平台 |
| 小红书声明 | 简介需加：「本账号所述内容为个人意见，不代表任何官方意见。」保险三件套不要放 | 公司合规 |
| 视频号/抖音声明 | 简介需加：「本账号上所陈述或表达的内容仅为我个人意见，并不代表友邦人寿的意见」+ 营销服务部 + 营销员编号 | 公司合规 |
| 品牌字 | 简介中不可写「友邦」「友邦保险」「AIA」（视频和图文笔记可以） | 公司合规 |

## 二、昵称 & 唯一识别号

- 账号唯一识别号（微信号 / 小红书号 / 抖音号）**不得包含**友邦及附属：
  友邦、友邦保险、友邦人寿、友邦上海、AIA、AIABJ、AIABEIJING、YOUBANG、YOUBANGBAOXIAN
  （中英文/拼音/大小写均禁）
- 若昵称与唯一识别号分开（如微信"名字"与"微信号"），昵称可含「友邦/AIA」，但须清楚说明与友邦关系并明示分支公司，
  如「友邦人寿上海XXX保险营销团队XXX」「友邦广东保险营销员XXX」
- 认证资料须准确说明与友邦关系

## 三、头像

- 不得使用友邦所有的标牌（商标、服务标记、商品名称、标志、图标）
- 可用：穿着带友邦 LOGO 的衣服，或在友邦 LOGO 背景墙下拍摄的照片（须公司标准 LOGO）

## 四、小红书主页打卡图片

- 不可使用「友邦」「友邦保险」「招募」「招聘」「寻找友邦合伙人」「招友邦合伙人」等字样
- 不得出现以个人名义「招募、招聘」保险营销员等字样
- 软性表达可用：「欢迎来加入」；使用「寻找合伙人」「轻创业转型」「保险企业家」时须加双引号

## 五、视频 / 图文笔记（非简介）

- 可以宣传友邦，可多加友邦标签增加品牌曝光（简介例外）
- 近期有营销员因客户搜索「友邦」而获客

## 六、违规判定红线

**医疗引流**（名称/简介/视频/音频含以下易被判）：
- 引导线上/线下问诊、提供医疗服务
- 引导评论区讨论疾病
- 引导到视频号外学习医疗知识/领取资料/中医收徒
- 「疾病名称 + 引导沟通」最易被判定医疗引流

**招商加盟**：
- 为品牌/业务招商加盟
- 诱导项目创业/项目投资

## 七、修改次数限制（重要提醒）

| 项目 | 限制 |
|------|------|
| 视频号昵称 | 每年最多可修改 **5 次**（确定要慎重） |
| 微信视频号简介 | 暂无明确修改次数限制 |
| 小红书个人简介 | **7 天限修改 3 次**（频繁修改影响账号权重） |
