# 内容支线推荐排序规则 V1

## 目的

IP 账号最终仍遵循“保险 + 1”：可以从营销员的过往职业、家庭/生活身份、长期爱好和已有资料中识别多个泛内容候选，但最终只选择一个最值得长期经营的内容支线。

不能按照用户选择顺序、字段顺序或关键词首次命中来决定支线。例如同时选择“育儿”和“美食”时，应优先判断哪个方向更有利于吸引保险目标客群、增员对象并建立长期信任，而不是简单取第一个爱好。

## 评分维度

每个候选方向按 100 分制计算基础推荐分：

1. 保险目标人群重合度（30%）：内容天然吸引的人群，是否与家庭保障、财富规划等保险主要决策人群高度重合。
2. 客群价值（20%）：是否更容易触达家庭资产决策者、中高收入或较高净值人群。兴趣只能作为概率信号，不可直接断言某爱好等于高净值。
3. 增员价值（15%）：是否容易吸引有职业发展、收入提升、创业经营或职业转型意愿的人群。
4. 信任建立能力（15%）：是否容易通过持续利他内容形成专业、靠谱、长期信任，并自然连接保险服务。
5. 本人持续输出能力（15%）：必须来自本人真实、长期经历/身份/爱好；同等业务价值下，真实积累越深越优先。
6. 内容传播潜力（5%）：是否有持续选题、问题场景、讨论空间和可分享性。

年龄不硬编码为单一“30～50岁”门槛。第一版使用“是否覆盖家庭保障与财富决策阶段”判断；后续如取得友邦真实业务数据，再校准年龄和权重。

## 已知方向基础库

基础分不是最终结论，只是业务先验。真实个人积累仍会影响排序。

### 高优先级
- 育儿 / 亲子：90
- 教育 / 升学：88
- 健康 / 医疗 / 养老照护：86
- 创业 / 企业经营：85
- 家庭财务 / 财务常识：84
- 职场成长 / 职业转型：80
- 法律常识：78

### 中高优先级
- 高尔夫：78
- 网球：74
- 骑行：72
- 滑雪：72
- 运动健身：70
- 旅行：68
- 汽车：68
- 摄影：64
- 户外：64
- 跑步：63

### 连接型内容
- 读书：62
- 美食：55
- 宠物：54
- 影视娱乐：48
- 普通生活日常：45

说明：高尔夫、骑行、旅行等与客群消费能力可能有关，但只作为弱概率信号，必须结合城市、真实投入程度、目标客户和本人经历，禁止输出“做某运动的人就是高净值”等确定性判断。

## 推荐流程

1. 从 previousCareer、lifeRoles、hobbies 及已有真实资料中识别全部候选，不采用 first-match。
2. 候选归一化为标准内容方向，并去重；同一方向可以记录多个真实来源。
3. 已知方向读取基础库；未知方向进入统一评分框架，不因为词库未收录而直接丢弃。
4. 根据本人真实积累进行调整：直接身份/职业证据优于泛兴趣；长期、可持续、能提供利他内容的证据加分。
5. 根据营销员做自媒体目的（拓客 / 增员）调整相应维度；不得牺牲保险主线。
6. 对所有候选排序，保留排序结果和推荐依据。
7. IP 方案最终只展示排名第一的“内容支线”；内部可以保留候选排序，供未来解释、修改或重新选择。
8. 分数接近时，优先选择与保险目标人群重合度更高、本人真实积累更强的方向。

## 未知方向判断

词库无法穷尽所有方向。遇到桨板、马术、茶文化、收藏等新方向时，应按同一套六维标准判断：
- 主要吸引什么年龄和家庭阶段的人？
- 与保险购买/家庭资产决策者重合度如何？
- 与潜在增员对象重合度如何？
- 客群消费能力/资产决策能力是否存在合理的概率关联？
- 能否持续输出真正利他的内容？
- 营销员本人是否有足够真实积累？

未知方向的判断结果后续可沉淀回基础库，但不能仅凭一次 AI 推断永久提高基础分。

## 产品验收案例

- 爱好同时选择“育儿 + 美食”：育儿应排在美食之前；除非资料明确显示用户在美食领域拥有显著、长期、可利他输出的专业积累，足以改变综合评分。
- “骑行 + 美食”：通常骑行优先，但不能以“骑行=高净值”作为唯一理由。
- 教师经历 + 普通美食爱好：教育/升学通常优先。
- 医疗职业经历 + 旅行爱好：健康医疗通常优先。
- 所有候选都缺乏真实持续积累时，不应硬凑支线，可以提示继续补充资料。

## 后续校准

V1 是业务规则基线，不把未经验证的客群年龄、收入或爱好画像写成事实。后续优先使用友邦真实业务经验、培训反馈、实际获客/增员转化数据校准基础分和权重，并保留版本记录。
