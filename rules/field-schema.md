# 字段来源与采集规范（v4）

> 代码化版本见 `../src/fields-schema.js`。前端按 `source` 分组渲染表单。

字段分三类来源：
- **questionnaire**：已收回问卷（57 人，持续补充）
- **backendExcel**：后台 Excel 可批量获取
- **toCollect**：建议补充收集（决定人设深度，优先收集）

## A. 问卷字段（questionnaire）

| 字段 | 说明 | 工具用途 |
|------|------|----------|
| 姓名 | 与后台 Excel 交叉校验 | 身份识别 / 资料匹配 |
| 营销员编号 | 9 位数字；仅用于身份识别、资料库匹配和历史资料恢复 | **不得当成执业证编号输出** |
| 培训确认 | 全勤线下培训 + 社群陪跑要求 | — |
| 简单自我介绍（自媒体优势） | 已有问卷数据可继续作为 AI 内部参考，但不再主动向用户询问 | 喂「人设优势判断轮」 |
| 微信视频号昵称 / ID / 粉丝数 | — | 现状参考；ID 禁含友邦拼音 |
| 小红书号 / 粉丝数 / 主页链接 | — | 现状参考；号禁含友邦拼音 |
| 自媒体成效（缘故/转介绍·公域咨询·业绩转化） | — | 喂「成就」维度 |
| 做自媒体主要目的 | ★ | 内容规划参考 |
| 当前账号运营状态 | — | — |
| 运营卡点（可多选） | — | Phase2 内容规划 |
| 每周愿投入时间 | — | — |
| 未达预期打算 | — | — |

## C. 建议收集字段（toCollect）

| 字段 | 取值示例 | 工具用途 |
|------|----------|----------|
| 学历 | 本科 / 硕士 / 博士 | 学历维度判定 |
| 最高学校背景 | 985 / 211 / QS50 / QS100 / 校名 | 学历维度关键依据 |
| 是否有留学背景 | 是/否 + 留学院校 | 留学=学历可突出 |
| 保险从业时间 | 9 年 | 喂「专业」维度 |
| 荣誉 | MDRT / TOT / COT / 五星会员 | 喂「成就」维度 |
| 擅长领域 | 教育金规划 / 养老规划 / 资产传承 | 喂「专业」维度 |
| 营销服务部 | 成都一部 | 视频号 / 抖音简介合规末尾 |
| 执业证编号 | 真实执业证编号 | 视频号 / 抖音简介合规末尾；若暂未采集，生成预览使用 `000` 占位并提醒发布前替换 |

## 身份字段与合规字段边界

- `agentId`（营销员编号）：9 位，用于匹配资料库、恢复历史资料、内部身份识别。
- `licenseId`（执业证编号）：用于视频号 / 抖音简介合规声明。
- 两个字段语义不同，**禁止用 `agentId` 自动填充 `licenseId`**。

## 判断轮维度映射

| 六维度 | 数据来源 |
|--------|----------|
| 身份/职位 | 荣誉职级、培训确认角色、问卷 |
| 性格特质 | 已有自我介绍自述、客户反馈（不再主动要求填写自我介绍） |
| 地域 | **城市**（后台 Excel） |
| 专业 | 保险从业时间 + 擅长领域 + 资质 |
| 学历 | 学历 + 最高学校背景 + 留学背景 |
| 成就/荣誉 | 荣誉（MDRT等）+ 自媒体成效 + 粉丝量 |

> **学历维度铁律**：仅当名校(985/211/QS)/硕士及以上/有留学背景/博士 任一满足才值得突出；
> 普通本科、大专、未知 → 不突出，绝不暴露短板。
> C 类字段缺失 → 标记「信息不足·暂不突出」，绝不臆造。
