# AIA Auto IP 内容规划业务规则 V4

> 自 V4 起，独立“内容规划”产品流程已撤销。**当前权威输出规则为 `rules/ip-content-strategy-rules.md`**；本文件继续保留内容边界和方法原则，供生成与后续维护参考。

## 1. 当前产品形态

内容规划不再是顶部独立功能，也不再单独提问和生成方案。

用户只完成一次 IP 信息采集，系统直接在 IP 方案底部生成“你的内容主线”。业务目标直接读取 IP 档案中的 `purpose`，不得再重复询问拓客 / 增员。

## 2. 专业内容与泛内容

账号长期内容仍分为：

- **专业内容主线**：服务于已确认的业务目标。拓客时是面向准客户的保险专业内容；增员时是转型、行业、公司团队、个人成长、从业日常等内容；两者都要时可以同时给出两条专业主线。
- **泛内容支线**：保险和直接增员内容以外的独立话题，例如育儿、升学、户外、骑行、运动、法律、职场成长等。

拓客 / 增员的边界以 `rules/content-goal-boundary-rules.md` 为准。

## 3. 泛内容的作用与边界

泛内容主要用于：

- 增加账号真实感和丰富度；
- 打开保险专业内容以外、更宽的话题和流量入口；
- 展示本人真实兴趣、经历和长期积累。

泛内容必须能脱离保险独立成立，也不能变成直接招聘广告。保险、保障、保单、理赔、投保、保费、教育金保险、养老保险等不能当泛内容。

选择标准：真实积累、可持续性、受众宽度、人群匹配、利他价值。

**没有本人真实证据时宁可暂不确定，不允许系统为了凑齐结构自行猜一个兴趣方向。**

## 4. 输出已经从“筛选过程”改为“结论”

用户不再看到：

- 候选方向；
- 候选筛选理由；
- 独立最终方向大卡；
- 不建议混入方向；
- 独立内容方向大板块。

系统可以内部完成比较，但页面只展示每条主线的：

1. 内容方向；
2. 合集推荐；
3. 对账号的作用标签。

合集名称 **最多 5 个汉字**，详细规则见 `ip-content-strategy-rules.md`。

## 5. 面向营销员的术语

禁止使用旧内部理解词：

- 保险 + N
- 保险 + 1
- 1 + 1

统一使用：

- 你的内容主线
- 保险专业主线 / 拓客内容主线
- 增员内容主线
- 泛内容支线

## 6. 聚焦原则

泛内容长期只保留一个明确方向。拓客和增员都要时允许同时存在两条专业主线，但同一阶段仍应有明显主次，避免账号在“面向客户”和“面向潜在新人”之间高频跳转。

内容聚焦提醒必须保留在 IP 方案的内容主线板块底部。
