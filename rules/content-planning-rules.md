# AIA Auto IP 内容规划业务规则 V2

> 本文件是当前内容规划业务定义的权威规则。若旧文档仍出现“保险 + N”“保险 + 1”“1 + 1”等历史内部说法，以本文件为准；这些内部理解词不得继续出现在面向营销员的界面或结果中。

## 1. 两条长期主线

每个账号的长期内容结构由两条主线组成：

1. **专业内容主线**：保险、保障、风险管理、家庭保障、养老保障、教育金、财富保障等与营销员专业服务直接相关的内容。
2. **泛内容支线**：必须是保险专业内容以外的独立话题方向，例如育儿、升学规划、户外、骑行、运动、法律、财商、职场成长、女性成长、城市生活等。

泛内容不是“换一种方式讲保险”，也不是“保险知识的细分领域”。如果一个方向的核心仍然是保险、保障、保单、理赔、投保、保费、保险产品或保险方案，它就属于专业主线，不能再被当成泛内容候选。

## 2. 泛内容支线的作用

泛内容支线同时承担两种作用：

- **增加活人感和账号丰富度**：让账号不只有专业知识，也能持续呈现真实的人、兴趣、经历、生活方式和价值判断。
- **打开更大的流量入口**：纯保险内容天然受众较窄；泛内容可以进入更广的话题池，吸引原本不会主动搜索保险内容的人，再通过长期关注建立信任。

因此，选择泛内容不能只问“和保险客户有没有关系”，也不能为了转化强行把每个泛内容话题再拐回保险。

## 3. 泛内容候选的硬边界

候选方向必须同时满足：

- 主题本身可以脱离保险独立成立；
- 营销员本人有真实经历、长期兴趣、专业积累或稳定观察来源；
- 有足够多可持续选题，不是只能偶尔发一两篇；
- 对更广泛受众有独立价值，可以提供知识、经验、观点、陪伴、启发或生活参考；
- 与营销员希望吸引的人群、个人气质或长期身份不明显冲突；
- 不依赖虚构经历，不为了流量硬蹭本人并不熟悉的热门赛道。

### 明确排除

以下内容不能作为泛内容支线：

- 家庭保障、健康保障、财富保障；
- 保险理念、保险科普；
- 保单、理赔、投保、保费、保险产品；
- 教育金保险、养老保险、年金、寿险等保险细分主题；
- 任何本质上仍然是在讲“怎么买保险、为什么要保险、保险怎么配置”的方向。

## 4. 泛内容候选的判断标准

每个候选方向按以下五项判断：

1. **真实积累**：本人是否有真实经历、兴趣、职业背景、家庭角色、学习积累或长期实践。
2. **可持续性**：是否能稳定延展出至少几十个选题，而不是三五篇就写完。
3. **受众宽度**：这个方向是否有比纯保险内容更广的天然受众和话题入口。
4. **人群匹配**：被这一话题吸引的人，与账号希望长期连接的人群是否基本一致或相容。
5. **利他价值**：内容是否能让受众获得知识、经验、方法、启发或情绪价值，而不只是展示个人生活。

优先选择同时满足“本人真的懂 / 能长期讲 / 受众够广 / 对别人有用”的方向。

## 5. 候选与最终方向

系统可以给出多个**候选方向**供比较，但最终只能推荐 **1 个**泛内容支线。

结果页必须满足：

- 板块名称使用“候选方向”，不使用“候选筛选”；
- 候选方向只写泛内容本身，例如“育儿与升学”“骑行与户外”“法律常识”，不要写“保险 + 育儿”等组合词；
- 最多只能有 1 个候选标记“推荐”；
- 被标记“推荐”的候选名称必须与结果页顶部的最终泛内容方向名称完全一致；
- 如果推荐的是“育儿与升学”，其他候选即使可以保留展示，也不得再出现第二个“推荐”；
- 后续内容方向、选题和合集参考必须围绕已经确认的这一个泛内容方向展开，不能同时经营多个互不相关的泛内容主线。

## 6. 专业主线与泛内容支线之间的关系

两条主线长期并行，但彼此边界清楚：

- 专业主线负责专业认知、风险教育、保障知识、服务信任与业务相关内容；
- 泛内容支线负责扩大话题入口、增加活人感、展示真实积累和长期价值；
- 泛内容不要求每篇都强行转回保险；
- 真正发生自然关联时可以偶尔连接，但不能把泛内容重新做成“披着泛内容外衣的保险科普”。

## 7. 面向营销员的表达规则

界面和生成结果中禁止出现以下内部术语：

- “保险 + N”
- “保险 + 1”
- “1 + 1”

如需要解释方法，统一使用：

- “先从多个泛内容候选中比较”
- “最终确定一个长期泛内容方向”
- “专业内容主线 + 泛内容支线”

内部可以用“1 + N”帮助理解候选过程，但不得作为面向营销员的产品文案或结果标签。
