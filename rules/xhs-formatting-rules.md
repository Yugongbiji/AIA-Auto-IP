# 小红书排版规则 V3

> 本文件补充并更新 `docs/脚本改写与小红书排版规则.md` 中的小红书排版部分。发生冲突时，以本文件为准。

## 0. 排版前先清理“脚本库结构标记”

有些输入来自脚本库，里面会带为了内部管理而加的结构标记。这些标记不是正文内容，进入小红书排版前应先删除。

### 0.1 多个候选标题

如果开头有 1 / 2 / 3 三个候选标题：

- 只保留第一个标题；
- 第一个标题前的 `1.`、`1、`、`标题1：` 等序号/标签全部删除；
- 第二、第三个标题整行删除；
- 不把“标题1 / 标题2 / 标题3”带进最终排版。

例如：

```text
1. 为什么越努力越焦虑
2. 成年人的焦虑从哪里来
3. 你不是不努力，只是方向错了
```

清理为：

```text
为什么越努力越焦虑
```

### 0.2 章节结构标记

以下属于内部脚本结构标记，全部删除标签本身：

- `开头`
- `正文`
- `正文1 / 正文2 / 正文3 ...`
- `结尾`
- `脚本正文`
- `文案正文`

如果标签后面同一行还有真实正文，只删标签，保留正文。

例如：

```text
开头：买房最怕什么？
正文1：很多人第一反应是房价跌。
正文2：但真正麻烦的是现金流。
结尾：所以买房前先算清楚自己的承受力。
```

清理为：

```text
买房最怕什么？
很多人第一反应是房价跌。
但真正麻烦的是现金流。
所以买房前先算清楚自己的承受力。
```

### 0.3 边界

- 这里删除的是**脚本库元数据/结构标签**，不属于“修改原文”；
- 除上述明确结构标签外，不得擅自删除正文；
- 如果无法确认某一行是不是结构标签，宁可保留，不猜测删除。

## 1. 不改正文

完成上述结构清理后，小红书排版只允许增加换行、空行和与语义匹配的表情符号，不得修改、删除、替换、调换正文任何文字或标点，不新增观点、事实、承诺或营销引导。

## 2. 段落与阅读节奏

- 每段最多 2 个完整句子；
- 长句优先在逗号、分号、冒号等自然停顿处换行；
- 标题独立成行；
- 不使用 Markdown 井号、星号等 AI 式排版符号；
- 目标是手机端扫读时，一眼能抓住重点，不出现连续大段文字墙。

## 3. 表情符号不是装饰，而是视觉锚点

表情的任务是帮助读者快速识别关键词、场景和段落作用。

### 3.1 核心词优先

出现明确核心词时，优先在核心词后或对应句首加入匹配表情。例如：

- 理赔 / 赔付：✅
- 合同 / 条款 / 责任：📄
- 风险 / 提醒 / 注意：⚠️
- 健康：❤️
- 医疗 / 医院：🏥
- 教育 / 升学：🎓
- 育儿 / 孩子：🧸
- 养老 / 银发：🌿
- 家庭 / 父母：👪
- 保障 / 保单 / 保险：🛡️
- 投保：📝
- 预算 / 保费 / 税务：🧾
- 财富 / 资产：💰
- 社保 / 医保 / 政策：🏛️
- 法律：⚖️
- 骑行：🚴
- 跑步：🏃
- 游泳：🏊
- 运动：🏅
- 户外：🏕️
- 旅行：✈️
- 企业主：🏢
- 创业：🚀
- 职场：💼
- 团队 / 服务 / 沟通：🤝 / 💬
- 数据 / 比例 / 金额：📊
- 案例 / 选择：🔎
- 故事：📖
- 重点 / 核心：📌
- 方法 / 建议：💡
- 清单：📋
- 步骤 / 计划：🧭

同一篇文章不要机械重复一种表情，应根据语义尽量丰富。

### 3.2 密度规则

- 整体目标：**平均每 1～2 句话至少出现 1 个表情锚点**；
- 任何连续 2 个完整句子中，至少有 1 个表情；
- 如果两句话都没有明显关键词，则选其中一句加入中性表情，例如 📌、💡、✨、✅；
- 有明显关键词时优先使用语义表情，不要为了凑数量全部使用中性表情；
- 一句话内通常最多增加 1～2 个表情，避免堆叠成“表情墙”；
- 不要求每一句都必须有表情，重点是阅读节奏稳定、视觉锚点足够。

## 4. 关键词强调规则

“核心词加表情”不是要求给每一个名词都加，而是：

1. 优先识别标题、段落中心词、专业关键词、场景关键词、结论词；
2. 同一句中多个关键词时，只选择最重要的 1～2 个做视觉强调；
3. 同一关键词在短距离内重复出现时，不必每次重复加相同表情；
4. 表情不得插入产品名称、数字、固定专有名词内部；
5. 加表情后必须保持原文字符顺序完全不变。

## 5. 输出验收

每次小红书排版完成后至少检查：

- 多标题输入是否只保留第一个标题，且序号已去掉；
- `开头 / 正文1 / 正文2 / 正文3 / 结尾` 等脚本库标记是否已经清理；
- 正文文字和标点是否完整保留；
- 每段是否不超过 2 个完整句子；
- 是否存在连续 2 句话完全没有表情；
- 核心词附近是否有合适的语义表情；
- 表情是否足够丰富，而不是全文只重复 📌 / ✨；
- 是否存在过度堆叠、影响阅读的表情；
- 长文整体是否形成稳定的“文字—视觉锚点—留白”节奏。
