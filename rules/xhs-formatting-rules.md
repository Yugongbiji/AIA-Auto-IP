# 小红书排版规则 V2

> 本文件补充并更新 `docs/脚本改写与小红书排版规则.md` 中的小红书排版部分。发生冲突时，以本文件为准。

## 1. 不改原文

小红书排版只允许增加换行、空行和与语义匹配的表情符号，不得修改、删除、替换、调换原文任何文字或标点，不新增观点、事实、承诺或营销引导。

## 2. 段落与阅读节奏

- 每段最多 2 个完整句子；
- 长句优先在逗号、分号、冒号等自然停顿处换行；
- 标题独立成行；
- 不使用 Markdown 井号、星号等 AI 式排版符号；
- 目标是手机端扫读时，一眼能抓住重点，不出现连续大段文字墙。

## 3. 表情符号不是装饰，而是视觉锚点

表情的任务是帮助读者快速识别关键词、场景和段落作用。

### 3.1 核心词优先

出现明确核心词时，优先在核心词后或对应句首加入匹配表情。例如：

- 理赔 / 赔付：✅
- 合同 / 条款 / 责任：📄
- 风险 / 提醒 / 注意：⚠️
- 健康：❤️
- 医疗 / 医院：🏥
- 教育 / 升学：🎓
- 育儿 / 孩子：🧸
- 养老 / 银发：🌿
- 家庭 / 父母：👪
- 保障 / 保单 / 保险：🛡️
- 投保：📝
- 预算 / 保费 / 税务：🧾
- 财富 / 资产：💰
- 社保 / 医保 / 政策：🏛️
- 法律：⚖️
- 骑行：🚴
- 跑步：🏃
- 游泳：🏊
- 运动：🏅
- 户外：🏕️
- 旅行：✈️
- 企业主：🏢
- 创业：🚀
- 职场：💼
- 团队 / 服务 / 沟通：🤝 / 💬
- 数据 / 比例 / 金额：📊
- 案例 / 选择：🔎
- 故事：📖
- 重点 / 核心：📌
- 方法 / 建议：💡
- 清单：📋
- 步骤 / 计划：🧭

同一篇文章不要机械重复一种表情，应根据语义尽量丰富。

### 3.2 密度规则

- 整体目标：**平均每 1～2 句话至少出现 1 个表情锚点**；
- 任何连续 2 个完整句子中，至少有 1 个表情；
- 如果两句话都没有明显关键词，则选其中一句加入中性表情，例如 📌、💡、✨、✅；
- 有明显关键词时优先使用语义表情，不要为了凑数量全部使用中性表情；
- 一句话内通常最多增加 1～2 个表情，避免堆叠成“表情墙”；
- 不要求每一句都必须有表情，重点是阅读节奏稳定、视觉锚点足够。

## 4. 关键词强调规则

“核心词加表情”不是要求给每一个名词都加，而是：

1. 优先识别标题、段落中心词、专业关键词、场景关键词、结论词；
2. 同一句中多个关键词时，只选择最重要的 1～2 个做视觉强调；
3. 同一关键词在短距离内重复出现时，不必每次重复加相同表情；
4. 表情不得插入产品名称、数字、固定专有名词内部；
5. 加表情后必须保持原文字符顺序完全不变。

## 5. 输出验收

每次小红书排版完成后至少检查：

- 原文文字和标点是否完整保留；
- 每段是否不超过 2 个完整句子；
- 是否存在连续 2 句话完全没有表情；
- 核心词附近是否有合适的语义表情；
- 表情是否足够丰富，而不是全文只重复 📌 / ✨；
- 是否存在过度堆叠、影响阅读的表情；
- 长文整体是否形成稳定的“文字—视觉锚点—留白”节奏。
