# 内容规划首次进入互动规则 V4（已停用）

> 状态：**已停用，仅保留历史说明。**
>
> 自 V4 起，AIA Auto IP 不再提供独立“内容规划”入口和第二轮 onboarding。最新规则以 `rules/ip-content-strategy-rules.md` 为准。

## 当前产品规则

内容规划已经合并进 IP 人设：

- 不再播放独立内容规划欢迎卡；
- 不再问 `primaryGoal`；
- 不再单独询问专业主线和泛内容候选；
- 不再要求用户点击“生成内容规划”；
- 直接读取 IP 档案中的 `purpose`、服务人群、服务能力、真实经历、IP 标签等资料；
- 精简后的“你的内容主线”直接展示在 IP 方案底部。

`purpose` 是唯一业务目标来源：

- 拓客；
- 增员；
- 拓客和增员都要；
- 打造个人品牌。

## 历史兼容

旧内容规划 API、历史消息和方案数据暂时保留，避免破坏已有数据。它们不再构成新用户的产品流程。

如果以后重新引入独立内容规划功能，必须重新经过产品确认，不能因为旧代码仍存在就自动恢复入口。
