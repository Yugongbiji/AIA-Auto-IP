# 内容规划首次进入互动规则 V2

## 目标
内容规划第一次进入时，不直接丢问题。先用产品化欢迎卡解释价值，再带入已有 IP 信息，只补决定内容方向的关键问题。

## 首次进入结构
1. 功能欢迎卡
2. 已有 IP / 营销员信息确认
3. 第一个未完成的内容规划问题

## 功能欢迎卡
采用与“脚本改写”欢迎卡一致的卡片样式，不使用纯文字说明。

核心包装：
- 把“今天发什么”变成一套能长期积累的内容主线。
- 先把保险主线定清，避免内容过杂。
- 从真实经历和目标人群里筛出唯一的“保险 + 1”支线。
- 最终落到内容方向、合集思路和可持续选题框架。

首次提示：接下来只需要回答 3 个关键问题。

## 已有信息带入
如果已有 IP 方案或报名资料，优先展示 2～4 个代表性信息，例如：
- IP 定位
- 服务人群
- 个人优势
- 做自媒体目的

明确说明这些信息会自动带入，不需要重复回答。

## 问题顺序
固定按以下顺序检查：
1. primaryGoal：账号主目标，只允许 **拓客为主 / 增员为主** 二选一；不提供“两者兼顾”，避免第一步就失去主目标。
2. insuranceFocus：保险内容主线
3. secondaryMaterials：可作为“保险 + 1”的真实积累和泛内容候选

每次只问第一个未完成问题。

## 首次无可带入信息
不要出现“没有资料”“没找到资料”等失败式表达。
欢迎卡后直接说明：会问 3 个关键问题，再根据回答把主线、支线和选题框架收束出来。

## 历史用户
- 已有内容规划方案：不重复播放欢迎卡，直接恢复最新方案，可继续提出调整要求。
- 有未完成的内容规划对话：恢复历史，并从未完成问题继续，不重复从第一题开始。

## 体验原则
- 少问：已有信息不重复问。
- 先讲价值再提问。
- 每屏只推进一个关键决策。
- 主目标必须明确，不用“两者兼顾”回避选择。
- 不使用“系统没找到”“资料不足”等让用户产生失败感的表达。
