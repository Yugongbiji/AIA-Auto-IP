# IP 人设产品规则 V13（历史阶段规则 / 部分 SUPERSEDED）

> V13 提交于 2026-08-21。后续 2026-08-24/25 的产品基线与最新有效需求总账已经覆盖其中若干维度。
>
> **当前实现不得直接以本文件为最高事实源。** 先读 `docs/product/CURRENT_EFFECTIVE_REQUIREMENTS_LEDGER_20260825.md`；本文件仅保留未被后续需求替代的 V13 决策轨迹。

## 1. 学历选项

V13 当时定义：大专 / 本科 / 硕士 / 博士 / 不希望填写。

当前有效版本：

- 大专
- 本科
- 硕士
- 博士

`不希望填写` 已被后续“所有问题删除其他 / 不希望填写 / 跳过等逃逸项”的规则 `SUPERSEDED`。

## 2. 账号表达风格（继续有效）

- 可选 1～2 项并允许自行补充；
- 明确提示“这个选择会影响后续的脚本改写风格”；
- 账号风格是长期偏好；具体脚本仍优先服从题材适配、事实准确和合规边界；
- 脚本改写的“稿件处理说明”应明确说明账号表达风格是否/如何被代入。

## 3. 做自媒体目的（原则继续有效，字段已升级）

V13 已确认首次阶段只提供拓客 / 增员，不再提供“拓客和增员都要”“打造个人品牌”。

后续规则进一步升级为：

- 最终字段为标准化 `primaryGoal`；
- 历史 purpose 若为两者都要 / 兼顾 / 打造个人品牌 / 打造专业形象等非唯一值，必须重新询问；
- 后续目标人群、IP 方案、内容方向和脚本推荐全部读取同一 `primaryGoal`。

## 4. IP 内容方向（旧术语部分已替代）

V13 的“先聚焦一个增长目标、只保留一条专业主线”原则继续有效。

后续规则已经把旧“拓客内容主线 / 增员内容主线 / 泛内容支线”术语升级为：

- `保险主线`：拓客时来自受控保险业务主题；增员时为增员与职业发展主线；
- `内容支线`：来自本人真实身份、经历、兴趣、客户反馈等证据；生活兴趣不得进入保险主线；
- 页面板块名统一为“内容方向”。

## 5. 服务型简介（原则继续有效，数量已升级）

继续有效：

1. 服务只能从营销员已提交/导入的真实字段提取，例如 `services / serviceAreas / serviceCapabilities / expertise / specialties`；
2. 无真实资料证据不得自行补充；
3. 服务项尽量简短；
4. 可使用全角竖线 `｜` 分隔；
5. 小红书不强行加入保险/养老/财富/医疗等敏感服务词。

已被后续规则替代：

- `SUPERSEDED`：“视频号 / 抖音两套简介”。当前每个平台是 **三套**：专业背书 / 人设记忆 / 价值服务。
- 固定声明、营销服务部、执业证编号不能由服务型简介自己追加，统一由 `ip-policy-core.js::complianceFooter()` 唯一输出。
