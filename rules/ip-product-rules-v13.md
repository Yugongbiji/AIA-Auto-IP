# IP 人设产品规则 V13

> 适用范围：IP 首次问答、账号表达风格、简介方案、IP 内容主线。
> 本文件补充并覆盖此前与下列事项冲突的旧规则。

## 1. 学历选项

“最高学历”快捷选项固定为：

- 大专
- 本科
- 硕士
- 博士
- 不希望填写

## 2. 账号表达风格

问题保持可选 1～2 项并允许自行补充，同时必须明确提示：

> 这个选择会影响后续的脚本改写风格。

账号风格是长期偏好；具体脚本仍需优先服从题材适配、事实准确和合规边界。

## 3. 做自媒体目的

首次阶段只提供两个快捷选项：

- 拓客
- 增员

不再提供“拓客和增员都要”“打造个人品牌”等选项。

提问时明确提示：刚起号阶段建议先选定一个方向开始，更容易让账号定位和平台画像保持清楚；该选择会直接影响 IP 方案里的内容主线。

历史档案如果仍是“拓客和增员都要 / 两者兼顾 / 打造个人品牌”等旧值，本阶段重新询问并收束为“拓客”或“增员”。

## 4. IP 内容主线

保险专业主线只保留一个：

- 选择“拓客” → 只生成“拓客内容主线”；
- 选择“增员” → 只生成“增员内容主线”。

不再同时生成拓客主线和增员主线。

泛内容支线仍可以保留一条，但必须来自本人真实兴趣、经历或积累；没有证据时显示“暂未确定”。

## 5. 服务型简介

视频号 / 抖音简介的两套方案中，允许有一套“服务清单型”简介。

规则：

1. 服务内容只能从营销员已经提交或导入的资料中提取，例如 `services`、`serviceAreas`、`serviceCapabilities`、`expertise`、`specialties`；
2. 没有真实资料证据时不得自行补充；
3. 每项服务尽量浓缩为 4 个汉字以内，例如“养老规划”“保障规划”；
4. 多项服务使用全角竖线 `｜` 分隔；
5. 必须保留视频号 / 抖音原有营销服务部、执业编号占位和个人意见声明等合规要求；
6. 小红书简介不强行加入上述保险/养老/财富/医疗等服务词，避免触发小红书简介敏感词规则。

## 6. 核心原则

**先聚焦一个增长目标，再生成一个保险主线；简介可以显得丰富，但服务内容只能来自真实资料，不能为了好看而虚构。**
