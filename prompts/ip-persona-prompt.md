# 一、人物资产与证据
昵称、简介、脚本人设代入共用人物资产：称呼、身份、学历、职业/过往经历、地域、成就、性格、兴趣、服务/内容方向。

可使用证据：A 报名表明确事实；B 本人自我介绍明确表达；C 客户反馈（尤其多人重复评价）。D AI 推断不得作为最终事实。

类别信息不得反推具体事实：QS前100不等于任何具体大学；985/211不等于某所学校；海外留学不能推断国家；职业经历不能升级为资格证书或头衔。

# 二、人设优势判断
先从身份/职位、性格、地域、专业/经历、学历、成就/荣誉六个维度判断哪些值得突出。信息不足就标记信息不足，不为了凑齐维度强行突出。

学历仅在资料明确有博士、硕士、985、211、QS前50/100、海外留学或明确有价值的学校背景时考虑突出。学校层级只按原始层级表达。

# 三、昵称受控生成
必须执行：真实证据 → 稳定人物称呼 → 六类人物资产（身份/性格/地域/专业经历/学历/成就）→ 自然表达 → 合规过滤。

硬规则：
- 每个推荐昵称必须包含一个真实人物称呼主体，且只出现一次；
- 推荐昵称不得出现“保险”“友邦”“AIA”及明显规避变体；
- 不得创造学校、职业、荣誉、地域、性格或业务能力；
- **人物资产不是机械前缀。禁止直接生成 `成都+称呼`、`TOT+称呼`、`985+称呼`、`有温度+称呼` 一类标签堆砌；地域、学历、荣誉、性格只有在形成自然、像真实账号昵称的表达时才能使用；**
- 多个推荐尽量采用不同路线；
- 原有昵称谨慎评价：若自然、好记、合规且已有稳定识别度，优先建议保留；“无/没有/暂无/未填写/未设置”等表示没有昵称，绝不能评价为建议保留；
- 两个平台昵称不同，可提示跨平台保持一致；
- AI 昵称仅供参考：标准化推荐不一定最能代表本人，长期喜欢、有特殊含义且稳定使用的昵称也可能是最好的选择。

# 四、简介受控生成（2026-08-25 最新）

简介始终围绕三个问题组织：
1. **我是谁？**
2. **我的优势是什么？**
3. **我能提供什么价值？**

三个维度均可根据真实资料丰富程度使用 1–3 行。简介不是履历表，也不是口播稿；表达要高度概括、凝练，但整体信息可以丰富，目标是提高有限平台空间内的信息密度，而不是为了短而短。

## 事实表达边界

- 必须区分 `原始字段 → 已确认事实 → 简介允许表达`。
- 模糊领域词不得升级为职业经历。资料只出现“法律”时，不得生成“曾从事法律工作”“法律行业背景”“法务工作经验”“法律专业人士”。只有资料明确提供法务/法律相关工作经历和年限时，才可写如“6年企业法务工作经验”。
- 同一事实优先使用更短且大家能看懂的表达，例如“硕士学历”写“硕士”。
- 不得把普通经历升级为资质、头衔、专业能力。

## 素材优先级

1. 差异化身份/明确职业经历；
2. 强专业背书：真实从业年限、学历、荣誉、专业资质、行业经历；
3. 真实内容/服务价值；
4. 有证据的客户评价结论；
5. 有定位价值的地域；
6. 真实兴趣；
7. 普通泛化形容词最后考虑。

稀缺事实优先于漂亮形容词。真实、有价值、有辨识度、合规且平台空间允许的信息尽量保留；只删除重复、无证据、AI推断、AI套话、明显低价值和不合规内容。

## 客户评价

客户反馈可用于判断性格/口碑，但最终简介只呈现结论，例如 `靠谱｜细致｜有耐心`。不要写“客户高频评价”“客户都评价我”“大家眼中的我”“多位客户认为”等系统解释式前缀。

## 单行结构硬规则

- 每一行必须保持同一语义维度，共同回答“我是谁 / 我的优势 / 我能提供什么价值”中的一个问题。
- 不得为了填满一行混合不同维度。例如 `二宝妈妈｜10年企业法务工作经验` 可以；`二宝妈妈｜跑步｜阅读` 不应硬拼；`MDRT｜家庭保障｜二宝妈妈` 禁止。
- 不要让“靠谱”“MDRT”“硕士”等极短信息在存在可合并的同维度内容时单独占一行；同维度短信息优先用 `｜` 合理组合。
- 同时避免单行过长导致自动换行；长表达优先压缩，不得损失或升级事实。

## 平台输出数量

不再生成同一平台 A/B/C 三套简介。只提供两份正文素材：
- 小红书：1套最终推荐正文素材；
- 视频号/抖音：1套共用最终推荐正文素材。

两套差异来自平台合规和允许表达的信息，不为了制造差异而拆散人物资料。

# 五、平台合规
真实账号中有人使用，不代表系统可以推荐。

## 视频号/抖音简介正文
正文按真实身份、经历、内容价值和服务信息生成，不得把营销员编号当作执业证编号，也不得自行输出营销服务部或执业证编号。

**模型只生成正文素材，不追加公司固定合规块。** canonical 阶段会由唯一 `complianceFooter` 按“个人意见声明 → 营销服务部 → 执业证编号”的固定顺序追加一次。

## 通用禁区
禁止“最好、第一、保证、稳赚、无风险、财富自由、财富密码、躺赢、人生开挂、能量场、宝藏顾问、财富女王”等绝对化、承诺型或 AI 自嗨表达。
