# 一、人物资产与证据
昵称、简介、脚本人设代入共用人物资产：称呼、身份、学历、职业/过往经历、地域、成就、性格、兴趣、服务/内容方向。

可使用证据：A 报名表明确事实；B 本人自我介绍明确表达；C 客户反馈（尤其多人重复评价）。D AI 推断不得作为最终事实。

类别信息不得反推具体事实：QS前100不等于任何具体大学；985/211不等于某所学校；海外留学不能推断国家；职业经历不能升级为资格证书或头衔。

# 二、人设优势判断
先从身份/职位、性格、地域、专业/经历、学历、成就/荣誉六个维度判断哪些值得突出。信息不足就标记信息不足，不为了凑齐维度强行突出。

学历仅在资料明确有博士、硕士、985、211、QS前50/100、海外留学或明确有价值的学校背景时考虑突出。学校层级只按原始层级表达。

# 三、昵称受控生成
必须执行：真实证据 → 稳定人物称呼 → 六类人物资产 → 自然表达 → 合规过滤。每个昵称只含一个真实人物称呼主体；禁止机械标签墙、虚构事实和保险/AIA等不合规昵称。原昵称自然、好记、合规且有稳定识别时优先保留；“无/没有/暂无/未填写/未设置”不能建议保留。推荐通常 3–5 个不同路线，AI 推荐仅供参考。

# 四、简介受控生成（2026-08-25 #92–#101 最新）

简介始终围绕三个问题：**我是谁 / 我的优势 / 我能提供什么价值**。三个维度均可按真实资料丰富程度使用 1–3 行。简介不是履历表或口播稿；单条表达凝练，整体信息可以丰富，目标是有限空间内的信息密度与视觉平衡。

## 事实表达边界
- 必须区分 `原始字段 → 已确认事实 → 简介允许表达`。
- 模糊领域词不得升级为职业经历。只有明确提供法务/法律相关工作经历和年限时，才可写如“6年企业法务工作经验”。
- 同一事实优先短而准确，例如“硕士学历”写“硕士”。
- 不得把普通经历升级为资质、头衔、专业能力。
- **时间精度必须保留。** 原始资料有明确年限时优先保留数字，如 `7年多` 优先表达为 `7年+`；不得降级成“长期经验”。只有原资料明确支持“多年”时才可写“多年”，不得自行增加“多年/长期”等时间判断。

## 素材、去重与客户评价
优先：差异化身份/明确职业经历 → 强专业背书 → 真实内容/服务价值 → 有证据客户评价 → 地域 → 真实兴趣 → 泛化形容词。有效真实信息尽量保留，不做机械减法。

整份简介必须做**跨行语义去重**，不能只做字符串去重。多个表达高度重叠时，优先保留：**具体量化事实 > 明确身份/经历/资质 > 明确荣誉 > 模糊概括 > AI 总结**。例如已有“10年建筑行业财务经验”，不得再用“长期财务管理经验”重复同一信息；“10年建筑行业财务经验”和“财务中级职称”分别是经历与职称，不算重复，可以同时保留。

客户反馈最终只呈现结论，例如 `靠谱｜细致｜有耐心`，禁止“客户高频评价/客户都评价我/大家眼中的我/多位客户认为”等解释前缀。

## 单行结构与版面硬规则
- 每一行必须保持同一语义维度，共同回答三个核心问题之一。
- 过往经历与荣誉原则上分开；但 `MDRT`、`法学本科`、`财务中级职称` 等短资产若单独成行会浪费空间，可与同属于“我的优势”且语义自然的真实信息合并。
- 正文去除 Emoji、标点、分隔符后，优先达到约 **12 个汉字等效宽度以上**；不足时按“同维度合并 → 凝练重组 → 并入相邻同核心维度行 → 不单独成行”处理，禁止加废话凑字。
- **视频号/抖音正文优先控制在 12–20 个汉字等效宽度；21–25 仅在保持自然完整表达确有必要时允许；25 是绝对上限。** 英文、数字、Emoji、标点按视觉宽度折算，不能机械按 Unicode 字符数。
- 多行长度尽量接近，避免一行接近上限而另一行只有几个字。真实性和语义完整优先，不为等长添加废话。
- 同一份简介正文每行使用不同 Emoji；淘汰 `👤`。Emoji 与行内容自然匹配，不得抢夺注意力。
- 固定合规声明完全豁免上述正文最低/最高宽度、均衡和 Emoji 规则。

## 正文行数与平台一致性
- 除固定合规声明外，正文**默认至少 3 行**。只有真实有效资料确实不足，继续增加会造成重复、空话或事实推断时，才允许少于 3 行；绝不能为了凑 3 行编造或重复。
- 小红书与视频号/抖音正文默认使用**同一套真实人物信息**。只有明确的平台合规规则造成差异时，才针对相应平台删除或替换不合规内容；不得为了制造平台差异主动删掉另一平台同样合规的有效信息。
- 生成顺序：充分挖掘真实资料 → 强事实排序 → 跨行语义去重 → 覆盖三个核心问题 → 尽量达到 3 行以上 → 12–20 优先/25 红线排版 → 再次跨行去重 → 平台合规差异处理 → 固定声明追加。

## 平台输出数量
只提供两份正文素材：小红书 1 套最终推荐正文；视频号/抖音 1 套共用最终推荐正文。两套默认人物信息一致，差异只来自明确的平台合规规则，不为制造差异拆散人物资料。

# 五、平台合规
## 小红书正文
正文不得出现保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学、友邦、AIA及联系方式/导流/利益诱导/夸大承诺等。模型不生成固定声明；canonical 必须在最终简介最后追加且逐字保持：`本账号所述内容为个人意见，不代表任何官方意见。`

## 视频号/抖音正文
不得把营销员编号当执业证编号，不得由模型生成营销服务部或执业证编号。canonical 必须在正文之后连续追加三行，原文、顺序、换行固定：
`本账号上所陈述或表达的内容仅为我个人意见，并不代表友邦人寿的意见`
`营销服务部：XXX`
`执业证编号：XXX`
三行固定尾部不受正文行宽限制。

## 通用禁区
禁止绝对化、承诺型或 AI 自嗨表达；真实账号有人使用不代表系统可以推荐。
