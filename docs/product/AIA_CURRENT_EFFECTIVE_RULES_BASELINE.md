# AIA 当前有效规则基线

## 目的

本文件是 AIA Auto IP 当前最高有效产品规则总账。所有代码、测试、需求变更必须以本文件为最高业务依据。

历史规则、旧版本规则文件、临时兼容逻辑不得覆盖本基线。

## 规则优先级

需求说明 → 当前有效规则基线 → Rule Owner → 代码实现 → 自动测试 → 发布。

## IP 人设生成规则

IP 输出必须基于真实用户资料，不允许凭空补充经历、能力、评价。

生成顺序：

1. 真实资料收集
2. 事实竞争与筛选
3. IP 定位
4. 一句话 IP
5. 简介
6. 内容方向

禁止：

- 简单字段拼接
- 兴趣替代核心职业价值
- AI 编造优势
- 无证据生成客户评价

## 简介规则

简介围绕三个核心问题：

1. 我是谁
2. 我的优势
3. 我能提供什么价值

之后追加：

4. 一句话 IP
5. 合规声明

素材充分时必须充分展示，不得无理由压缩为低信息量文本。

## 客户反馈规则

本人优势与他人评价必须严格分离。

本人资料：strengths 等字段。

他人评价：peer_reviews。

只有真实 peer_reviews 才允许出现：

- 多人反馈
- 客户评价
- 大家认为

禁止根据 AI 推断制造群体评价。

## 问询规则

IP 资料采集必须由字段 Schema 驱动。

每个字段必须明确：

- 是否必填
- 数据来源
- 影响功能
- 缺失处理方式

已有有效资料可以跳过，没有有效资料不得跳过。

重点字段包括：

- 基础身份
- 城市
- 过往经历
- 生活角色
- 爱好
- 服务能力
- 内容表达风格

## 发布原则

开发 → Preview → 自动测试 → 人工验收 → 冻结 RC → Production。

Production 不允许重新拼装未验收代码。
