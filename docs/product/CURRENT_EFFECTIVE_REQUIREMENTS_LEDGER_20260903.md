# AIA Auto IP 最新有效需求增量总账（2026-09-03）

> **当前最高产品事实源增量。** 本文件仅记录 2026-09-03 新确认/修订的规则，不替换、不删除 `CURRENT_EFFECTIVE_REQUIREMENTS_LEDGER_20260825.md` 的其他有效规则。
>
> 判定原则：本文件对相同维度有明确修改时，以本文件为准；本文件未涉及的维度，继续严格继承 2026-08-25 总账及其委托的专项规则。任何代码、Prompt、稳定稿、动态 fallback、测试和发布验收均必须执行本文件。

## 1. 自媒体运营经验退出昵称 / 一句话 IP / 简介素材池

- 自媒体运营经验只用于了解学员运营基础，不属于对外人设资产。
- 账号运营时长、运营平台、粉丝量、播放量、作品量、咨询量、留资量，以及通过自媒体获得的客户转化、成交、增员等，均不得进入推荐昵称、一句话 IP、推荐简介，也不得参与这三类输出的强事实竞争。
- 无论上述数据高低均执行同一规则，不因粉丝量、咨询量、成交量较高而放宽。
- 只有主持人、记者、媒体从业者等“媒体/内容本身就是其真实职业身份或职业经历”时，才按职业事实规则参与 IP / 简介；账号运营成绩仍不得因此进入。
- 过往职业仍不得机械进入新生成推荐昵称。

## 2. 简介必须先过平台合规门禁，再成为最终推荐稿

- 最终推荐简介不是“先生成、复制时再提醒合规”，而是生成结果本身必须已经通过对应平台合规检查。
- 小红书简介正文严格执行 `rules/compliance-rules.md`：不得出现 `保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学` 等小红书简介敏感行业词；不得出现 `友邦 / AIA` 等品牌字；不得出现电话、微信、邮箱、QQ、微博、二维码或其他导流信息；不得输出执业证编号。
- 一句话 IP / headline 因为需要逐字复用于小红书简介，也必须通过小红书共同合规围栏，不得含上述小红书简介禁用词。
- 视频号 / 抖音正文同样先经过对应平台合规规则；固定合规声明中的法定/公司要求文字不参与正文敏感词误判。
- 平台合规过滤必须发生在最终推荐输出之前；任何未通过合规检查的候选不得作为“推荐简介”展示给用户。

## 3. 固定合规声明必须完整追加

- 小红书简介最后一句逐字固定为：`本账号所述内容为个人意见，不代表任何官方意见。`
- 视频号 / 抖音简介末尾固定连续三行，顺序不得变化：
  1. `本账号上所陈述或表达的内容仅为我个人意见，并不代表友邦人寿的意见`
  2. `营销服务部：XXX`
  3. `执业证编号：XXX`
- 营销员编号不等于执业证编号，不得拿营销员编号冒充执业证编号。
- 营销服务部和执业证编号缺失时不得由 AI 编造；按现有缺失字段规则处理，并在正式发布/复制前补齐真实值。

## 4. 当前行业从业年限的对外价值门禁

- 当前行业从业不足 5 年，默认不作为推荐简介或一句话 IP 的人物卖点，不输出“不到一年 / 1年+ / 2年 / 3年 / 近4年”等低价值从业年限。
- 该规则的目的不是隐藏真实资料，而是区分“真实存在”与“值得作为对外人设资产推荐”。原始资料仍保留，不删除。
- 当前行业从业满 5 年及以上，可在确有背书价值、且平台合规允许时参与简介/IP竞争；对外表达使用 `5年从业经验 / 10年从业经验` 等自然表述，不在小红书简介中写 `保险从业X年`。
- 从业年限即使满 5 年，也不是必选项；仍需与更强的学历、职业经历、荣誉、家庭身份、客户评价、兴趣等真实资产竞争。

## 5. 行业内部职级 / 黑话不得作为陌生客户卖点

- `A1`、`PA转任`、`团队1+2` 等只有行业内部人员才能理解的职级、缩写、晋升口径，默认不进入推荐简介和一句话 IP。
- 除非未来产品规则明确确认某项称谓对普通目标客户具有清晰、可验证、合规的外部认知价值，否则不得因为“晋升快”就把内部职级包装成人设亮点。
- 对 MDRT、COT、TOT 等已有专项规则明确允许的行业荣誉，继续按原最高规则进行真实性、价值与平台合规竞争，不受本条机械删除。

## 6. 资料不足人员采用稳定稿增量补充，不无故重生成

- 对只有客户反馈、没有基本资料的人，如果现有真实证据只能支持 1–2 行人物正文，可以少于 3 行；不得为了凑行编造身份、经历、服务能力或泛化价值。
- 此类人员一旦形成合规、真实的稳定昵称 / 一句话 IP / 简介，后续补充基本资料时默认执行**增量补充**：保留当前已经成立的稳定内容，只把新确认且更有价值的信息增加或优化进现有结果。
- 不得因为补充了新资料就无理由把原稳定稿整体推翻、重新随机生成。
- 只有以下情况允许修改/替换原稳定内容：新增资料证明原内容存在事实冲突；原内容违反最新合规/最高规则；新增事实明显更强且需要做信息竞争；或用户明确提出修改。
- 增量更新后仍必须重新执行事实、去重、平台合规、行宽、Emoji、固定声明等最终门禁。

## 7. 执行要求

生成顺序统一为：

`读取现有稳定稿 → 读取新增真实资料 → 排除自媒体运营素材 → 事实证据分级 → 人物资产竞争 → 低价值从业年限/内部黑话过滤 → 昵称/IP/简介规则生成或增量补充 → 平台合规硬检查 → 固定声明追加 → 最终输出`

- 批量预生成稳定稿、网页动态生成 fallback、数据库稳定输出、Prompt、唯一 Owner 与自动测试必须采用同一规则，禁止只在 Excel 人工稿中执行。
- 后续如发现新问题，继续以最小增量方式追加/修订最高规则，不得为增加一条规则而覆盖或破坏原总账其他内容。
