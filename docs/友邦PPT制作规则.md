# 友邦PPT制作规则

## 1. 适用范围

本规则用于“红人计划”及 AIA Auto IP 相关培训、功能介绍、操作指引类 PPT。目标是让营销员能快速看懂、愿意尝试，并能按图完成操作。

## 2. 参考模板与交付原则

- 以《何不发布数据复盘合规》为版式参考，沿用其 16:9 比例、母版、页码、标题节奏、红色标注方式和留白关系。
- 新PPT应使用参考模板中的版式页编辑而成，不将模板或整页截图扁平化。
- PPT成品属于培训交付物，不上传 Git；仅将本规则和与产品相关的文字规则纳入 Git。

## 3. 视觉系统

- 主色：友邦红 `#D31145`；内容页以白色为主，深色文字承载正文。
- 辅色：浅粉红用于轻量强调，浅灰用于信息底板；风险通过绿色提示。避免紫色、杂色和大面积高饱和背景。
- 封面可使用友邦红底、半透明粉色几何折面与白色品牌标识；标题保持大而克制。
- 内容页沿用左上角“双红方块 + 深色标题”的识别形式，并保留页码、页边距与品牌装饰。

## 4. 页面结构

每个功能介绍PPT统一采用以下叙事：

1. **功能首页**：以产品发布的方式展示该功能最有代表性的电脑端/手机端界面，并用一句话说明价值。
2. **功能特色**：用 3–4 个可感知的能力点说明“为什么值得用”，避免空泛口号。
3. **操作步骤**：从进入功能、输入内容、系统处理到获得结果，按实际操作顺序逐页展示。
4. **使用提醒或下一步**：说明复制、人工核对、合规确认或进入下一项工具的正确动作。

## 5. 截图与操作标注

- 截图是操作页主体，应使用当前产品页面或依据当前产品逻辑制作的模拟界面；不得使用真实营销员、客户姓名、编号或隐私资料。
- 一页只讲一个主要动作；单张截图最多突出 3 个位置。
- 使用友邦红箭头、圆角气泡和编号标识操作位置；阅读顺序遵循从左到右、从上到下。
- 标注文案使用动词开头，例如“粘贴原稿”“确认修改”“点击查看方案”，避免长段解释。
- 截图应清晰、比例统一，保留足够留白；不使用模糊、拉伸或与页面无关的装饰图片。

## 6. 文案与信息密度

- 标题表达页面结论，而非只写栏目名称；一行放不下时应缩短文案，不缩小到难以阅读。
- 正文短句化，功能特色每点不超过两行；一页不堆砌多个步骤或大量规则。
- 数据、限制和合规要求只使用已确认的信息；没有依据的数字、案例和效果不得自行添加。
- “AI生成”应被表述为高质量初稿：发布前仍需完成事实、合规、口播和人设匹配核对。

## 7. AIA Auto IP 功能页专属要求

- **账号内容规划**：突出 IP 读取、保险 + 1、三项筛选原则、内容方向与对话微调。
- **智能脚本改写**：突出知识点锁定、IP匹配、三版改写、合规检查和人工核对。
- **小红书排版**：突出不改变原意、短句分段、语义表情、风险提示与标签建议；确认修改风险表达时转入脚本改写。

## 8. 交付检查

- 检查标题是否换行、文字是否超出截图或页面边界、箭头是否指向正确位置。
- 检查截图、页码、品牌元素和字体是否一致；内容页不使用过多红色正文。
- 逐页预览后再交付，确保操作路径与当前产品逻辑一致。
