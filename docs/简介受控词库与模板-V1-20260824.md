# 简介受控词库与模板 V1

> 状态：2026-08-24 用户确认。用于 AIA Auto IP 的推荐简介生成与验收。

## 1. 最高原则

简介必须优先回答三个问题：

1. **我是谁？**——体现人设：真实身份、职业/过往经历、家庭身份等。
2. **我有什么优势？**——体现专业：与人设相关的真实经历、学历、资质、荣誉、年限、影响力。
3. **我能给你带来什么？**——体现价值：关注账号能获得什么内容或真实服务方向，不承诺结果。

简介不是履历表。目标是让陌生人在约 10 秒内知道“这个人是谁、为什么值得关注”。

## 2. 人物资产与证据等级

昵称、简介、脚本人设代入共用同一套人物资产：称呼、身份、学历、职业、地域、成就、性格、兴趣、服务/内容方向。

证据等级：

- A：报名表明确事实；
- B：本人自我介绍明确表达；
- C：多人客户反馈；
- D：AI 推断。

A/B/C 可作为素材；D 原则上禁止进入最终简介。类别信息不得反推具体事实，例如“QS 前 100”不能推断具体大学，“海外留学”不能推断国家。

## 3. 素材优先级

1. 差异化身份/经历：博士、前教师、前 HR、创业经历、宝妈等；
2. 强专业背书：从业年限、真实荣誉、专业资质、行业经历；
3. 真实内容/服务价值；
4. 有证据的客户高频评价；
5. 有定位价值的地域；
6. 1–2 个真实兴趣爱好；
7. 普通泛化形容词最后考虑。

**稀缺事实优先于漂亮形容词。**

## 4. 受控素材

### 4.1 家庭/生活身份

可从真实资料提取：妈妈、宝妈、二宝妈、爸爸、宝爸等。不得自行创造婚育情况。

### 4.2 职业/经历

允许提取真实职业和过往经历，如教师、医生、律师、HR、财务、银行从业者、创业者、企业管理者、教练、精算师等。不得把普通经历升级成资质或头衔。

### 4.3 学历

可使用资料明确提供的博士、硕士、985、211、QS 前 50、QS 前 100、海外留学及明确校名。不得由层级、留学经历反推具体学校或国家。

### 4.4 专业/成就

可使用资料明确提供的从业 X 年、MDRT、COT、TOT、真实专业资质、行业荣誉和影响力经历。优先具体证据，不使用“资深、顶级、权威”等 AI 自封表达。

### 4.5 性格

V1 受控候选：靠谱、真诚、细致、有耐心、理性、务实、有温度、温暖、阳光、行动力强、长期主义。

必须由本人资料、自我介绍或客户反馈支持。AI 感觉不构成证据。

### 4.6 兴趣

可从真实资料提取跑步、骑行、健身、旅行、阅读、美食、摄影、育儿、运动、户外等；一般最多 1–2 个，不固定死全部爱好，也不得创造。

## 5. 价值表达

优先使用“内容价值型”表达，例如：分享家庭成长中的实用经验、分享养老相关知识、聊职场转型与个人成长、分享育儿与家庭生活、记录跑步/生活/成长等。具体主题必须与本人资料一致。

“服务标签型”仅在本人资料明确存在且当前平台合规允许时使用，格式可为 `XXXX｜XXXX｜XXXX`，最多 3–4 项。不得因为营销员身份自动补充服务。

## 6. 三种固定生成策略

### A｜专业背书型

身份 → 1–2 个最强专业证据 → 真实内容/服务方向 → 关注价值。

适合学历、专业经历、荣誉较强的人。

### B｜人设记忆型

身份 + 差异化经历 → 有证据的性格/生活特点 → 专业证据 → 内容价值。

适合跨界职业、家庭身份、爱好或客户评价有特色的人。

### C｜价值服务型

我是谁 → 主要关注/擅长什么 → 合规的受控服务标签 → 关注后能获得什么。

适合服务方向明确但稀缺身份标签不强的人。

三个版本必须有策略差异，禁止同一段文字只替换少量词。

## 7. 自动删减规则

生成后必须执行减法检查：

- 4 个以上荣誉：保留最强 1–2 个；
- 多个类似职业身份：保留最有辨识度的；
- 同义性格词：合并；
- 兴趣最多 1–2 个；
- 服务项目最多 3–4 个；
- 同一事实不得重复；
- 没有证据的“专业、靠谱、认真、负责”等优先删除。

## 8. 合规围栏

真实账号中出现过，不代表系统可以推荐。所有简介必须再经过当前平台对应合规规则。

小红书简介当前硬性过滤包括但不限于：保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学、友邦、AIA、联系方式、其他平台账号、明显导流、利益诱导、夸大承诺、个人名义招募/招商等。

不得生成“财富自由、财富密码、躺赢、稳赚、无风险、人生开挂、能量场、宝藏顾问、财富女王”等 AI 自嗨或承诺型表达。

必要的组织/执业/免责声明应按平台固定规则处理，不交给 AI 自由发挥。

## 9. 生成流程

`原始资料 → 语义提取人物资产 → 标注证据来源 → 选择最强资产 → 选择 A/B/C 策略 → 受控组合 → 自动删减 → 平台合规过滤 → 最终简介`

AI 只负责排序、组合和自然表达；不得创造身份、经历、学历、学校、职业、荣誉、性格、兴趣、服务能力或其他事实。
