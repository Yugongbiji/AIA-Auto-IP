# 网页 MVP 交互与方案输出规则

## 生成前收集

- 已报名的营销员首次通过姓名和营销员编号匹配资料；后续补充保存到历史档案。
- 所在城市为报名表带入信息；本期报名人员统一为成都。
- 服务人群与客户年龄段拆成两个多选题：
  - 服务人群：企业主、职场白领、宝爸宝妈、都市银发、自由职业者、新市民；允许自行补充。
  - 客户年龄段：25–35 岁、35–45 岁、45–55 岁、55 岁以上。
- 保险从业时间填写具体数字。
- 优势、荣誉均为多选题；荣誉包含 MDRT、COT、TOT、五星会员并允许补充。
- 学历、学校背景、留学背景、希望呈现的气质、营销服务部均在生成前完成采集。
- 生成方案后不再主动追问信息；仅根据营销员主动提出的内容修改。

## 方案呈现

- 方案以独立预览页呈现，不显示 Markdown 的 #、* 等符号。
- 顶部展示一句话定位、三个标签；目标客户画像与优势使用横向信息区，并与其他卡片保留明显间距。
- 昵称给出 3 至 5 个选项，标注侧重点并支持一键复制。
- 小红书、视频号/抖音各给两套简介，分别突出专业背书与温暖陪伴等不同侧重点。
- 简介放在可复制文本框；使用人工换行、无空行；每行尽量控制在 16 个汉字左右，信息行以匹配的表情开头。
- 视频号/抖音简介使用 “📌 执业编号：000”，并提醒上传前替换为本人执业编号；不得使用内部营销员编号。

## 平台修改机会提醒

- 小红书个人简介：7 天限修改 3 次，频繁修改影响账号权重。
- 视频号昵称：每年最多可修改 5 次。
- 微信视频号简介：暂无明确修改次数限制。

提醒只描述平台限制，不提及工具内的对话或修改次数。

## 简介修改合规提示

方案预览页必须在平台修改机会提醒之前展示完整的合规提示，且由规则库固定提供，不由模型临时生成。

可表达：真实的个人经历、城市、专业服务方向、真实荣誉；小红书可使用“代理人”“养老规划师”等合规称谓；视频和图文笔记（非简介）可按公司规则宣传友邦。

避免写入：

- 微信号、手机号、邮箱、QQ、微博、二维码、其他平台账号及其他联系方式。
- “关注送福利”“私信领资料”等引导关注或利益诱导。
- 小红书简介中的保险、金融、理财、贷款、股票、基金、医疗、护理、教育、玄学、友邦、AIA 与执业证编号。
- “最好、第一、保证、稳赚、无风险”等绝对化、夸大或不实表述。
- 引导问诊、讨论疾病或站外学习医疗知识等医疗引流。
- 以个人名义招募、招聘营销员，招商加盟或诱导创业投资。
- 微信号、小红书号、抖音号中包含友邦、AIA 及其拼音或缩写。
