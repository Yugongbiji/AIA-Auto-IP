# 网页 MVP 交互与方案输出规则

## 生成前收集

- 已报名的营销员首次通过姓名和营销员编号匹配资料；后续补充保存到历史档案。
- 所在城市为报名表带入信息；本期报名人员统一为成都。
- 目标客户画像为多选题：年轻家庭、新中产家庭、企业主、女性成长、退休规划家庭；允许自行补充。
- 保险从业时间填写具体数字。
- 优势、荣誉均为多选题；荣誉包含 MDRT、COT、TOT、五星会员并允许补充。
- 学历、学校背景、留学背景、希望呈现的气质、营销服务部均在生成前完成采集。
- 生成方案后不再主动追问信息；仅根据营销员主动提出的内容修改。

## 方案呈现

- 方案以独立预览页呈现，不显示 Markdown 的 #、* 等符号。
- 顶部展示一句话定位、三个标签；目标客户画像与优势使用横向信息区，并与其他卡片保留明显间距。
- 昵称给出 3 至 5 个选项，标注侧重点并支持一键复制。
- 小红书、视频号/抖音各给两套简介，分别突出专业背书与温暖陪伴等不同侧重点。
- 简介放在可复制文本框；使用人工换行、无空行；每行尽量控制在 16 个汉字左右，信息行以匹配的表情开头。
- 视频号/抖音简介使用 “📌 执业编号：000”，并提醒上传前替换为本人执业编号；不得使用内部营销员编号。

## 平台修改机会提醒

- 视频号昵称：每年最多可修改 5 次。
- 微信视频号简介：暂无明确修改次数限制。
- 小红书个人简介：7 天限修改 3 次，频繁修改影响账号权重。

提醒只描述平台限制，不提及工具内的对话或修改次数。
