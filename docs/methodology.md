# IP 人设定位方法论（来自《IP人设智能工具202608.pdf》）

> 本文档从原始 PDF 思路稿中提炼出可落地的「人设打造方法」，作为工具 Prompt 的方法论底座。

## 一、什么是 IP

- **一句话总结：IP 就是让大家记住你。**
- **IP 一致性原则：**
  - 不用每个平台都做一套 IP；
  - 学会方法后，各平台去分发就好。

## 二、人设打造五步法

| 步骤 | 名称 | 要点 |
|------|------|------|
| 1 | 找对标 | 寻找可参考的同类账号（Phase2 功能） |
| 2 | 看反馈 | 收集身边同事/客户对自己的评价标签（靠谱、专业、人间清醒、行动派…） |
| 3 | 定昵称 | 六类命名策略，按优势维度选择（见下） |
| 4 | 定头像 | 职业照/生活照优先，避免卡通、网图 |
| 5 | 定简介 | 三段式万能公式（见下） |

## 三、六种昵称命名策略

| 策略 | 示例 |
|------|------|
| 突出身份 | 总监劲乐、廖大美律 |
| 突出性格 | 有温度的佳伦、富婆老萝莉 |
| 突出地域 | 上海西西说、海淀妈妈Cecilia |
| 突出专业 | 创业教练马俊、精算师Alex |
| 突出学历 | Dr.陈且聊讲保险 |
| 突出成就 | 年金一哥黄喜祥、锅冠海意许保险 |

> ⚠️ 工具实际生成时：**先做人设优势判断**，只给值得突出的维度出昵称；
> 且**尽量不用英文/拼音**（精算师Alex → 精算师小马，Dr.陈 → 陈博士）。

## 四、简介三段式万能公式

1. **我是谁？**（身份 + 背景）
2. **我能为你提供什么？** —— 必须从「自我介绍」转化为「对他人的价值」
   - 心理咨询师 → 每周一场线下心理疗愈
   - 马拉松爱好者 → 每周一场迷你马拉松
   - 十年亚非拉工作经历 → 国外旅游工作注意事项找我
   - 上海12333社保局经历 → 上海社保问题每周线上答疑
3. **我要什么诉求？** —— 大胆提出（获客 / 增员 / 品牌曝光）

简介三原则：**体现人设、体现专业、体现价值。**

## 五、输出物（工具最终交付）

- 一句话 IP 概括
- 推荐昵称（三平台统一，仅针对值得突出的维度）
- 小红书简介（单独一版）
- 视频号&抖音简介（共用一版）
- 合规声明自动追加

## 六、合规三件套（原始要求）

- **小红书**：本账号所述内容为个人意见，不代表任何官方意见。
- **视频号&抖音**：本账号上所陈述或表达的内容仅为我个人意见，并不代表友邦人寿的意见（并注明所在营销服务部 + 营销员编号）

> 更完整的合规规则见 `../rules/compliance-rules.md`。
