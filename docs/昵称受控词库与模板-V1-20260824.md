# 昵称受控词库与模板 V1

> 适用范围：AIA Auto IP 的“推荐昵称”生成与现有昵称评估。
> 数据参考：用户提供的《自媒体账号参考.xlsx》，共 14,840 条账号记录、8,260 个不同昵称。
> 重要原则：真实市场中存在的昵称，只能作为语料，不代表合规、适合或可推荐。系统推荐必须先过合规，再谈好记和特色。

## 1. 生成顺序

昵称生成必须按以下顺序执行：

1. 合规硬过滤；
2. 真实资料证据校验；
3. 确定唯一人物称呼主体；
4. 判断最值得突出的 1 个核心资产；
5. 从六类受控模板中选择；
6. 只从受控词库组合；
7. 受控模板均无法自然匹配时，才允许 AI 兜底；AI 兜底仍不得创造事实词。

## 2. 硬规则

### 2.1 必须有人物称呼主体

所有推荐昵称必须能够回答“这个账号是谁”。人物主体可来自：

1. 客户反馈中高频真实称呼；
2. 本人明确希望使用的称呼；
3. 已长期使用且无明显问题的原昵称中的人物称呼；
4. 本人姓名、名字简称；
5. 本人明确长期使用的英文名。

一个昵称只能保留一个人物称呼主体，不得出现“双称呼拼接”。

不合格示例：成都冲浪、暖心、养老规划、QS前100、成都生活家。

### 2.2 推荐昵称硬禁用词

以下词及明显变体不得出现在系统推荐昵称中：

- 保险
- 友邦
- 友邦保险
- 友邦人寿
- AIA
- AIABJ / AIABEIJING 等品牌缩写或变体
- 通过拆字、谐音、符号规避上述限制的写法

即使真实账号库中大量存在，也只能进入“反例语料”，不得进入推荐案例库。

### 2.3 类别信息不得推导具体事实

- QS 前 100 ≠ 某所具体大学；
- 985 / 211 ≠ 某所具体学校；
- 有留学背景 ≠ 某个国家或院校；
- 企业主 ≠ 某家公司；
- MDRT / COT / TOT ≠ 某个具体业绩数字；
- 宝妈 / 宝爸 ≠ 子女数量与年龄。

只有原始资料明确给出，才允许写具体事实。

## 3. 六类受控模板

### A. 突出身份

模板：

- `[真实身份] + [人物称呼]`
- `[人物称呼] + [真实身份]`

身份必须来自本人明确资料，不得自行创造头衔。

优先身份词（仅有证据时可用）：

- 老师 / 教师
- 律师
- 医生
- 教练
- 精算师
- HR
- 会计 / 财务
- 记者 / 主持人
- 程序员 / 科技从业者
- 创业者 / 企业主
- 宝妈 / 宝爸 / 妈妈 / 爸爸 / 奶爸

### B. 突出性格

模板：

- `[受控性格词] + [人物称呼]`
- `[有证据的性格表达] + 的 + [人物称呼]`

性格不得由 AI 凭空判断。优先来源：多人客户反馈高频词 > 本人明确自述。

第一版可用性格词：

- 靠谱
- 有温度
- 温暖
- 暖心
- 阳光
- 真诚
- 理性
- 务实
- 长期主义
- 热爱生活

“专业”原则上不作为性格词单独使用，更适合在专业/经历维度表达。

暂不开放 AI 常见自嗨词：

- 乘风破浪
- 闪闪发光
- 冲浪
- 宝藏
- 飒爽
- 松弛感
- 能量场
- 高能
- 女王 / 王者
- 人间清醒（除非本人或客户反馈明确长期使用且审核通过）

### C. 突出地域

模板：

- `[真实地域] + [人物称呼]`
- `[真实地域] + [人物称呼] + [受控连接词]`

地域必须直接来自资料，不做推断。

地域词库不固定城市名单，直接使用档案中真实城市/区县；默认只用一层地域，不同时堆叠“上海浦东陆家嘴”等多层位置。

### D. 突出专业 / 过往经历

模板：

- `[真实专业身份] + [人物称呼]`
- `[真实经历标签] + [人物称呼]`
- `[人物称呼] + [受控连接词] + [允许内容词]`

优先用稀缺、真实、能形成记忆的过往职业或专业经历；不得创造“专家、大师、权威、第一”等未经授权的高位称谓。

### E. 突出学历

模板：

- `[真实学历/学校层级] + [人物称呼]`
- `[真实学历标签] + [人物称呼] + [受控连接词] + [允许内容词]`

只有以下情况优先考虑：

- 博士；
- 硕士及以上且对个人定位有明显价值；
- 985 / 211；
- QS 前 50 / QS 前 100；
- 明确且真实的留学/海归经历。

若只有层级，没有学校名，只能写层级，绝不能补具体学校。

### F. 突出成就

模板：

- `[真实成就] + [人物称呼]`
- `[真实成就] + [人物称呼] + [受控连接词] + [允许内容词]`

候选成就必须有真实资料证据，并且先过合规审查：

- MDRT
- COT
- TOT
- 五星会员
- 销冠 / 冠军（仅当原始资料明确且允许公开使用）

不得把成就进一步夸张成“一哥、第一、顶级、最强”等绝对化表达。

## 4. 受控连接词

V1 只开放：

- 说
- 聊
- 讲
- 谈
- 看

优先级建议：`说 / 聊 / 讲` 高于 `谈 / 看`。

连接词不能独立成为人格特色，只负责让昵称更口语化。

## 5. 内容词分级

### 5.1 禁止进入推荐昵称

- 保险
- 友邦
- AIA
- 金融
- 理财
- 贷款
- 股票
- 基金
- 医疗

其中“保险 / 友邦 / AIA”是硬禁用，不因平台不同而放宽。

### 5.2 谨慎使用，不进入默认白名单

以下词可能在某些语境可用，但 V1 不让 AI 自动选择；只有明确业务/合规规则允许时才开放：

- 保障
- 财富
- 养老
- 教育
- 健康
- 传承
- 年金
- 规划
- 顾问

原因：容易与金融、保险产品或专业资质产生过强联想，必须结合平台与公司要求判断。

### 5.3 相对中性，可作为低风险候选

- 家庭
- 育儿
- 生活
- 成长
- 职场
- 创业
- 故事
- 日记
- 笔记

但依然必须与本人真实内容方向一致，不能为了好听硬塞。

## 6. 真实账号库的频次发现（仅作语料参考）

在 8,260 个不同昵称中：

- 人物称呼：含“姐”约 453 个，“哥”124 个，“老师”63 个；
- 表达连接：含“说”259 个，“聊”98 个，“讲”23 个；
- 性格：含“靠谱”40 个，“热爱生活”18 个，“阳光”17 个，“温暖”9 个；
- 家庭身份：含“妈妈”99 个，“宝妈”28 个，“爸爸”18 个；
- 学历/教育：含“海归”5 个，“博士”3 个，“985”3 个，“QS”2 个；
- 成就：含“MDRT”8 个，“COT”4 个，“TOT”3 个，“销冠”3 个。

这些频次只用于判断“自然不自然”，不能突破合规优先级。

## 7. 可参考的结构案例（已排除明显品牌/保险字样）

可研究结构，不代表可以原样复制：

- 靠谱大刘
- 上海玲佳说
- 北京霞姐
- 创业教练马俊
- 王博士看世界
- 从HR到销冠上海刘佳玲
- 魔都三宝妈
- 靠谱的金老师
- 有温度的安总妈妈

使用案例时仍需逐条检查：事实是否真实、头衔是否允许、成就是否可公开、是否适合当前平台。

## 8. 反例库

### 8.1 只有标签，没有人

- 成都冲浪
- 暖心
- QS前100
- 养老规划

原因：无法形成稳定人物识别。

### 8.2 双称呼

- 静姐说保障静静

原因：一个昵称出现两个称呼主体。

### 8.3 事实越界

用户只填写“QS前100”，系统却生成某具体大学。

原因：把类别信息错误推导为具体事实。

### 8.4 市场真实但系统禁止推荐

任何包含“保险 / 友邦 / AIA”的真实账号昵称。

原因：真实存在不等于当前推荐合规。

## 9. 推荐排序

系统先对真实资产进行价值排序，再选模板：

1. 稀缺且强的真实资产（博士、强职业经历、明确荣誉等）；
2. 多人客户反馈形成的稳定认知；
3. 已长期使用、客户熟悉的人物称呼；
4. 地域 / 家庭角色等稳定身份；
5. 一般性格词；
6. 中性内容词。

推荐 3–5 个昵称时，应尽量来自不同路线，而不是只换最后一个词。

## 10. AI 兜底边界

AI 只有在以下条件同时满足时才允许提出受控库之外的新组合结构：

- 六类模板均无法自然组合；
- 人物称呼已经确定；
- 所有事实词均来自真实资料；
- 不出现硬禁用和慎用未授权词；
- 不创造学校、职业、荣誉、地域、家庭、性格等事实；
- 生成后必须再过一遍合规和人物称呼校验。

AI 不是“自由取名器”，而是受控模板无法自然组合时的最后优化器。

## 11. 后续实现要求

在真正修改昵称生成代码前，需要：

1. 用户确认本 V1 词库；
2. 将词库转成机器可读配置，而不是散落在 Prompt 中；
3. 昵称生成先走规则引擎，AI 仅做最后兜底；
4. 自动回归至少覆盖：
   - 推荐昵称不得出现保险 / 友邦 / AIA；
   - 每个昵称必须有一个且仅一个人物称呼主体；
   - QS前100不能生成具体学校；
   - 原昵称“无/暂无/未填写”等不得进入评估；
   - 推荐昵称只使用真实资料中存在的身份、学历、成就、地域；
   - 3–5 个备选至少覆盖 2 个不同角度（资料允许时）。
