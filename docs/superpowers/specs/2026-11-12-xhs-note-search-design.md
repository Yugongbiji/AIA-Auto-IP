# 小红书笔记搜索设计

## 目标
在 AIA Auto IP 新增独立“小红书笔记搜索”工具，使用 Wellbyte V4 搜索真实笔记，支持在线列表、分页、互动数据本地排序、详情抽屉和 Excel 导出。

## 交互与行为
- 顶部新增“笔记搜索”入口，不改变既有四个工具。
- 搜索字段：关键词、笔记类型、排序、发布时间。排序包括综合、热度、最新、评论、收藏；收藏排序使用 collect_descending。
- 每次只请求用户当前页；分页参数与关键词和筛选条件共同传递。不同搜索条件切换时清空旧结果；跨页按笔记 ID 去重。
- 在线表格显示标题、类型、作者、发布时间、点赞、收藏、评论、分享。点击互动列标题可对当前页本地排序。
- 点击笔记标题打开右侧详情抽屉，展示封面、作者、日期、互动数据、正文摘要和笔记 ID。
- 点击抽屉中的原笔记入口时才按需请求 Wellbyte 笔记详情接口（成功可能扣 13 credits），不在搜索、翻页或打开抽屉时调用。仅当详情接口明确返回合法小红书 HTTPS 链接才展示打开入口；未返回则提示并提供复制笔记 ID。返回链接不等于已验证笔记仍可访问。
- Excel 默认导出当前已加载数据中按当前排序排列的前 50 条；不足 50 条全部导出；不自动请求剩余页。服务端强制最多 50 条。
- Excel 包含标题、正文摘要、发布时间、类型、作者、点赞、收藏、评论、分享、笔记 ID、原文链接；冻结首行、开启筛选。

## 安全与成本
- Wellbyte API Key 仅保存在服务器环境变量 WELLBYTE_API_KEY，不进入前端、日志、响应或仓库。
- API 代理在服务端请求 Wellbyte，前端不直接调用供应商。
- 只在搜索/翻页时调用供应商；导出仅使用已加载结果。
- Preview 通过 GitHub Actions secret 注入 WELLBYTE_API_KEY；未配置时给出明确提示，不影响其他工具。

## 验收标准
- 搜索参数和筛选值正确映射到 Wellbyte V4。
- 收藏排序使用 collect_descending。
- 分页结果与当前搜索条件一致；重复笔记按 ID 去重。
- 搜索、空结果、接口错误和缺少密钥均有明确状态。
- 详情抽屉可打开/关闭，按需详情查询后原文跳转与复制 ID 可用；无有效链接时不拼接猜测链接。
- Excel 最多 50 条，导出不产生搜索 API 调用。
- 原有四个工具的导航和用户旅程不回归。
