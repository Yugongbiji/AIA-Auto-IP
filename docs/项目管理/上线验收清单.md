- [ ] 能复用已有 IP 档案

## 12. 上线结论

只有以下三项都满足，才标记“本版本验收完成”：

1. P0 业务路径通过；
2. 自动 QA 与生产健康检查通过；
3. 产品负责人确认业务结果可用于真实培训/日常使用。
