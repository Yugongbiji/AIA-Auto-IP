## 3. 三轮审计后的系统性根因

已确认不是 80～85 几个孤立 Bug，而是以下七类根因：

1. canonical 数据生命周期太晚：过去只在 render 时修方案，下游/数据库仍可能读 AI 原始结果；
2. Owner 重复或缺失：客户反馈、Clipboard、完成度、部分方案字段存在双 Owner/无人认领；
3. Prompt 双规则源：运行时 `server.py` 旧硬编码 Prompt 与仓库 Prompt 不一致；
4. 退役逻辑泄漏：V30/V31/V33 或旧 content planning 能力曾继续影响新页面；
5. Preview 隔离不完整：API 已隔离但 localStorage / 正式 lookup 依赖仍可能串环境或拖慢；
6. 公共 UI 组件是假公共化：Loading/Clipboard 过去仍分散实现或依赖 MutationObserver；
7. 测试假保护：部分 E2E 仍验证已经被新需求废弃的行为，ECS 检查也覆盖不足。
