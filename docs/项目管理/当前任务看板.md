## 5. 简介最新规则与实现（2026-08-25 已确认）

### 最新核心规则

- [x] 始终回答“我是谁 / 我的优势 / 我能提供什么价值”，每个维度可 1–3 行。
- [x] 不再同一平台给 A/B/C 三套；最终只给小红书 1 套、视频号/抖音共用 1 套。
- [x] 取消机械减法和兴趣/服务/荣誉固定数量上限；真实高价值信息在空间允许时尽量保留。
- [x] 简介使用高度概括、凝练表达，例如“硕士学历”→“硕士”。
- [x] 模糊领域词不得升级成职业经历，例如“法律”不能变成“曾从事法律”。
- [x] 明确法务经历可概括成如“6年企业法务工作经验”。
- [x] 客户评价最终只呈现结论，如 `靠谱｜细致｜有耐心`，不出现“客户高频评价/客户都评价我”等解释前缀。
- [x] 单行必须保持同一语义维度；短信息同维度合并，过长表达压缩，不能为填满一行跨维度硬拼。
- [x] 固定合规尾部仍只有 `complianceFooter()` 一个 Owner。
